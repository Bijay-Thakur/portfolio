# V2 asset ledger

The world, motorcycle, landmarks, trees, bench, and lamp are original models authored in Blender 5.2 with [`make_assets.py`](../../assets/v2/blender/make_assets.py). Editable source: [`portfolio_v2_assets.blend`](../../assets/v2/blender/portfolio_v2_assets.blend). Materials are shared grayscale values; these GLBs have no external textures. No Bruno Simon models, map, code, branding, or artwork are bundled. The three user supplied images guided the terrain, bridge, and monochrome architectural direction and are not shipped as runtime assets.

The runtime terrain, bridge decks and rails, roads, water, mountains, directional signs, and collision shapes are generated by repo code. Geometry and materials are original project work.

The existing Cormorant Garamond and Nunito fonts are now served from local Latin WOFF2 files in `app/fonts/` so builds do not depend on Google Fonts network access. Both families are distributed under the [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/METADATA.pb) ([Nunito metadata](https://github.com/google/fonts/blob/main/ofl/nunito/METADATA.pb)). Cormorant Garamond is credited to the Cormorant Project authors; Nunito is credited to the Nunito Project authors. The font pairing and rendered V1 typography remain the same.
